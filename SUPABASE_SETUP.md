# Supabase Setup

This project requires Supabase tables, storage, and environment variables for services and admin uploads.

## 1. Create a Supabase project

Go to https://app.supabase.com and create a new project.

## 2. Create tables

Run the following SQL in the Supabase SQL editor:

```sql
-- Services table
create table if not exists public.services (
  id bigint generated by default as identity primary key,
  title text not null,
  description text not null,
  image_url text not null,
  created_at timestamptz default now() not null
);

```

## 3. Create storage bucket

- In Supabase, open Storage.
- Create a bucket named `site-images`.
- Set the bucket to public if you want uploaded images to be accessible directly by URL.

## 4. Configure environment variables

Add these variables to `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
SUPABASE_STORAGE_BUCKET=site-images
ADMIN_EMAIL=owner@example.com
```

## 5. Admin login flow

- Use the `/login` page to send a magic link to the email in `ADMIN_EMAIL`.
- After login, `/admin` becomes accessible and can upload service images.

## 6. Notes

- `SUPABASE_SERVICE_ROLE_KEY` is required by server-side upload code only.
- `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are used by client-side Supabase.
- For production, set the same environment variables in your deployment provider.
