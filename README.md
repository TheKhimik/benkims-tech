This is a [Next.js](https://nextjs.org) project using the App Router and Supabase for remote services and admin uploads.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Supabase Integration

This app supports:

- remote service cards from Supabase `services`
- image uploads to Supabase Storage
- admin authentication with Supabase magic links
- server-side admin upload protection using the Supabase service role key

### Required environment variables

Add the following to `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
SUPABASE_STORAGE_BUCKET=site-images
ADMIN_EMAIL=owner@example.com
```

- `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` are used by the public client.
- `SUPABASE_SERVICE_ROLE_KEY` is used only on the server in `lib/supabaseAdmin.ts` and the admin upload API.
- `SUPABASE_STORAGE_BUCKET` should match the bucket name used for uploads.
- `ADMIN_EMAIL` is the comma-separated list of admin email addresses allowed to upload images.

### Supabase schema

Create these tables in your Supabase database:

- `services`
  - `id` int8 primary key generated by default as identity
  - `title` text
  - `description` text
  - `image_url` text
  - `created_at` timestamp with time zone default now()

For the exact SQL, see `SUPABASE_SETUP.md`.

### Storage setup

- Create a bucket named `site-images` or update `SUPABASE_STORAGE_BUCKET` to your bucket.
- Make the bucket public or configure public access for uploaded files so the app can render them directly with `next/image`.

### Admin flow

- Open `/login` to send a Supabase magic link.
- Use the same email address listed in `ADMIN_EMAIL`.
- After login, the admin dashboard at `/admin` allows uploading `service` cards.
- The upload API is protected by email and the Supabase service role key.

## Local development

After adding `.env.local`, restart the dev server.

## Deploying

Set the same environment variables in your deployment environment.

If deploying to Vercel, add all env values under Project Settings and then redeploy.
